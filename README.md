# ⚽ Жребий

Анимирана церемония за разделяне на отбори: двама капитани теглят топчета с имена от урна,
показват листчето пред камерата и играчите отиват в техните отбори.

- **index.html** – 3D церемонията (Three.js)
- **zhrebiy.html** – по-простата 2D версия
- **models/** – 3D моделите на капитаните (`a.glb`, `b.glb`)
- **tools/** – конвертор от Mixamo FBX към GLB и `build-models.js` за версия, която се отваря с двоен клик

Имената на играчите се пазят само в браузъра на всеки потребител.
